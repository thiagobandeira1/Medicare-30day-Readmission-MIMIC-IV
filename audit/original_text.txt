  Motivation & Background
  30-day readmissions are a major healthcare challenge, linked to high costs and poorer outcomes.
  Medicare beneficiaries (age 65+) are particularly vulnerable to readmissions.
  Reducing readmissions is a key national priority, reinforced by CMS through the Hospital Readmissions Reduction Program (HRRP).
  Data-driven prediction at discharge can help primary care providers identify at-risk patients early and enable timely interventions.
  Source: Centers for Medicare & Medicaid Services (CMS), Hospital Readmissions Reduction Program.

  [PICTURE: Picture 55]
  Problem Definition
  Challenge: Identifying Medicare patients at highest risk of 30-day readmission is difficult at the time of discharge.
  Goal: Develop a predictive model using MIMIC-IV v3.1 dataset to assess readmission risk for Medicare beneficiaries.
  Outcome: Deliver an interpretable risk-scoring tool that supports primary care providers with targeted interventions.
  Impact: Missed risk predictions → avoidable hospitalizations, higher costs, poorer patient outcomes.

===== SLIDE 23 =====

  FT-Transformer
  23
  Purpose-built Transformer architecture for tabular data (Gorishniy et al., 2021)
  FT-Transformer = Feature-Tokenizer Transformer | [CLS] = Classification token
  How It Works
  1  Feature Tokenizer
  Numeric + categorical features → individual d-dimensional vector
  2  [CLS] Token
  Learnable summary token prepended to the feature tokens
  3  Self-Attention
  Each token attends to all others: discovers which features interact
  4  Classification
  [CLS] output → LayerNorm → Dense(64) → Sigmoid → readmission probability
  Why It Adds Value
  MLPs
  Blend all features together: interactions emerge implicitly through layers
  LightGBM
  Finds interactions via sequential tree splits: locally greedy
  FT-Transformer
  Explicitly learns which feature pairs matter via attention: global and differentiable
  Different error patterns → valuable for stacking ensemble

  GRU+MLP Architecture
  24
  How the Hybrid Model Works
  Sequence Branch
  10 prior admissions × 15 temporal features → GRU layers → temporal representation
  Static Branch
  25 numeric features + 5 categorical embeddings → Dense layers
  Fusion Layer
  Concatenate both branches → Dense(128) → Dense(64) → Sigmoid
  Table 2. Test AUROC
  Key finding: Standalone RNNs (0.636) confirm that sequences alone are insufficient. The hybrid approach combining temporal + static features is essential.
  GRU = Gated Recurrent Unit · LSTM = Long Short-Term Memory · MLP = Multi-Layer Perceptron · RNN = Recurrent Neural Network

  Limitations
  34
  Single Hospital System
  Data from Beth Israel Deaconess (Boston) only, which may limit generalizability to other hospitals, regions, or populations.
  No Unstructured Clinical Notes
  Physician notes, discharge summaries, and radiology reports were not used. NLP-based features could improve predictions.
  No Social Determinants of Health
  Housing stability, social support, health literacy, and transportation are known risk factors but unavailable in MIMIC-IV.
  Diminishing Returns
  Expanding features beyond the core clinical set yielded only marginal improvement, suggesting a ceiling with available structured data.
  Temporal Limitation
  30-day readmissions occurring at different hospitals are not captured in MIMIC-IV.
